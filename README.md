# Cal State LA Environmental Reports Dashboard

An interactive dashboard for viewing environmental health and safety reports for California State University, Los Angeles campus buildings.

## Overview

This dashboard provides a searchable, filterable index of environmental assessment reports across Cal State LA facilities. Reports can be filtered by building, hazard type, report type, and year.

## Features

- Filter reports by building, hazard type, report type, and year
- Sortable columns
- Direct links to report documents
- Mobile-friendly layout

## Contact

For questions about environmental reports, contact the Cal State LA Environmental Health & Safety office.
